# 🛡 AI Cyber Threat Detector

AI-powered cybersecurity dashboard for phishing and suspicious URL detection.

## 🚀 Features

- Phishing Detection
- Threat Severity Analysis
- Cybersecurity Dashboard
- Threat Analytics
- Real-Time Monitoring
- Security Recommendations

## 🛠 Tech Stack

- Python
- Gradio
- Pandas
- CSS
- Hugging Face Spaces

## 📌 Project Overview

This project analyzes suspicious messages and URLs using intelligent rule-based cybersecurity logic. It classifies inputs as SAFE or PHISHING and generates a real-time threat report.
